# 🎬 Movie List

**Movie List** is a simple and intuitive Android app that lets you build and manage a personalized list of your favorite movies. Add titles one at a time, categorize them, and sort or save your list with ease.

## 📱 Features

- Add movies with:
    - 🎞️ Movie Name
    - 🎭 Genre
    - 📅 Release Year
    - ⭐ Rating
- View all added movies in a scrollable list on the home screen
- Sort your list by:
    - Name (A–Z)
    - Release Year (Newest–Oldest)
    - Rating (Highest–Lowest)
- Use the 3-dot menu to access sorting options
- Tap **Add Movie** to input a new entry
- Tap **Save List** to persist your data even after closing the app

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest version recommended)
- Android SDK 24+
- Kotlin or Java support

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Technut10/MovieList.git
   ```
2. Open the project in Android Studio
3. Build and run on an emulator or physical device

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Android XML Layouts
- **Architecture:** MVVM (optional)
- **Storage:** SharedPreferences (for data persistence)
